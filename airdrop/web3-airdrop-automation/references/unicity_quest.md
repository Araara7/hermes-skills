# Unicity Quest (Sphere Quests)

## Overview
- **Website:** https://quest.unicity.network/
- **Type:** Incentivized testnet campaign
- **Reward:** XP → Token allocation at TGE
- **Wallet:** Sphere wallet (custom, bukan MetaMask)

## Stage 0 (Wajib)
1. Connect wallet (Sphere wallet)
2. Verifikasi Twitter (min 30 hari)
3. Verifikasi Discord (min 7 hari)
4. Complete basic tasks

## Daily Tasks
- Social tasks (like, retweet, follow)
- On-chain volume tasks
- Daily check-in (streak bonus)

## Multipliers
- Proof of Humanity → multiplier on all XP
- Phone verification → booster
- Streak bonus → consecutive days

## Referral
- Link: https://quest.unicity.network/?ref=YOUR_CODE
- Bonus: % of referee's XP
- Cap: 50 unique referrals

## Tech Stack
- Frontend: React + Vite
- Auth: JWT (stored in localStorage as `quest_jwt`)
- Wallet: Custom Sphere wallet (not MetaMask)
- API: GraphQL + REST

## Pitfalls
- ⚠️ Stage 0 wajib sebelum akses stage lain
- ⚠️ Twitter min 30 hari, Discord min 7 hari
- ⚠️ Satu akun per orang (sybil detection ketat)
- ⚠️ VPN bisa trigger flag
- ⚠️ Manual verification butuh 2 hari kerja
